FP&A Expected vs. Actuals Dashboard
Interactive variance analysis dashboard — upload your own CSV or Excel, or explore the built-in SaaS demo. Filter by quarter and cost center, with auto-generated insight callouts and a full variance table.
+

About this project

This is the tool that replaces the monthly Excel reconciliation an FP&A analyst spends 3–4 hours on during close week. A finance team drops their actuals export alongside the plan file and gets a fully formatted variance report instantly — no Python environment, no Streamlit cold starts, no broken dependencies.

Built as a self-contained HTML file with Chart.js and SheetJS for in-browser Excel parsing. Revenue is treated as an expectation (favorable when actuals beat plan), while cost lines use standard budget logic — a distinction most generic dashboards get wrong. The insight callout engine auto-generates contextual flags: R&D hiring ahead of plan, revenue recovery after a Q1 miss, COGS creep in H2.

Includes a downloadable sample Excel file so anyone can test the upload feature with realistic data from a different company profile than the default demo.

002InteractiveFinanceLive
Valence — DCF Valuation Calculator
Type any US ticker and a full 10-year DCF populates in real time — live financials via Cloudflare Worker, CAPM-derived WACC, sensitivity table, value bridge, and company-relative bull/base/bear scenarios.
+

About this project

A fully self-contained DCF model that runs entirely in the browser. Type in a ticker — AAPL, NVDA, CMG — and it pulls live financials from a Cloudflare Worker proxy, then populates a 10-year free cash flow model with TTM revenue, operating margins, net debt, shares outstanding, and a CAPM-estimated WACC using the stock's live beta.

The model outputs intrinsic value per share with upside/downside vs. the current price, a full FCF projection table, a value bridge, and a 5×5 sensitivity matrix across WACC and terminal growth rate. Every assumption is editable — bull, base, and bear cases scale proportionally to each company's actual growth profile rather than generic presets.

A "Why the Gap?" panel automatically surfaces data-driven explanations when the model diverges significantly from the market price — debt load, margin expansion stories, hypergrowth premiums, or moat/brand value the DCF can't capture. The architecture decision to use a serverless Cloudflare Worker as a proxy keeps API credentials off the client and eliminates cold starts entirely.

About

I studied Finance at the University of Delaware's Lerner College of Business with a minor in Fintech, and honestly the minor felt more like the point than an add-on. I've always been more interested in the places where finance and technology run into each other than in keeping them separate.

Over the past few years I've gotten comfortable with the full range of what a finance role can look like today: building models from scratch, working through earnings calls and SEC filings, writing investment memos, and more recently, building the kinds of tools that automate the parts of that work that don't need to be manual. Automation, data pipelines, and applied AI are where I think the next generation of finance professionals will separate themselves, and that's where I'm putting my energy.

What actually draws me to FP&A and corporate finance is the translation layer. Taking a messy set of numbers and turning it into something a leadership team can make a real decision with is genuinely interesting to me. I want to be in roles where finance has a seat at the strategy table, not just in the back office processing reports.

I built my first computer at 12 just by watching YouTube videos and figuring it out. That instinct hasn't really changed. If I don't understand how something works, I want to take it apart until I do, and then usually try to make it better.
