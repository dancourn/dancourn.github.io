Reflection

This project started as an experiment with prompt engineering and grew into a genuine productivity tool. I wanted to understand not just how to call an LLM API, but how to structure prompts so the outputs were actually useful for financial workflows — summarizing 10-Ks, drafting research memos, pulling signal from noise.

The biggest lesson: model behavior is highly sensitive to how you frame the task. Simple changes to instruction structure could take a mediocre summary and make it analyst-quality. That hands-on understanding of how these models actually behave is something I bring directly into any AI-adjacent finance role.

Over the past four years, I've built a foundation in financial analysis, budgeting, forecasting, and performance evaluation — while also getting hands-on with the tools reshaping how finance teams operate: automation, data modeling, and machine learning applications that make reporting faster and decisions sharper.
